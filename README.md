# MultiverseofWatch — Android starter project

This is an Android Studio project using a local WebView interface.

## Features in this starter
- Dark, mobile-first interface
- Anime catalog and search via Jikan API
- TV series search via TVmaze
- Anime movie category
- YouTube trailer search links
- Local favourites saved on the device
- Movie discovery link to IMDb (this starter does not yet have a live movie-rating API)

## Build
Open this folder in Android Studio, let Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s).

Package: com.multiverseofwatch.app
Minimum Android: 6.0 (API 23)

A compiled APK is not included in this ZIP. It must be built with the Android SDK/Gradle.
